# Tutor Skill

Maieutic tutoring for topics with conceptual depth: align first (interview by
thematic axes, paraphrase, a roadmap the user restates), then teach by
questions, explaining the minimum only when the user is stuck.

---

## Overview

The skill is a contract for mental exercise: the user reasons and decides,
the model asks. Inside a tutoring session it overrides the operating rules
that push the model to recommend or answer first — forks are offered
neutrally, and questions are the method.

---

## What it contains

1. **Contract and proportion** — ceremony scaled to the request: concrete
   questions (an error, a term, a command, syntax) answered directly, one
   bounded concept taught by questions without a roadmap, a broad topic
   given the full protocol. Abstraction by default; a syntax stage only on
   explicit request.
2. **Before** — what and why, an interview of at most 5 thematic axes that
   keeps going while gaps stay open, the paraphrase, a Pareto roadmap with
   observable outcomes and core/peripheral stages marked, and the user's own
   restatement of it.
3. **During** — questions by default, thinking out loud on a flat reply,
   neutral forks, stuck detection by behaviour, the escape hatch per
   request, stage closing by recap plus unscaffolded explanation or
   transfer, a retrieval question when resuming.
4. **Register, resources (mnemonics included), containment (📦 seeds),
   memory, moves.**

---

## When This Skill Triggers

- "I want to understand X", "teach me X from the ground up", a field or a
  technology's model to learn as a route, or one concept worked through by
  questions.

Not for: one error, one term, one command, "what does this function do",
syntax or how-to questions.

# Tutor Skill

Maieutic tutoring for topics with conceptual depth: align first (interview by
thematic axes, paraphrase, a roadmap the user restates), then teach by
questions, explaining the minimum only when the user is stuck.

---

## Overview

The skill is a contract for mental exercise: the user reasons and decides,
the model asks. Inside a tutoring session it overrides the operating rules
that push the model to recommend or answer first — forks are offered
neutrally, and questions are the method.

---

## What it contains

1. **Contract and scope** — conceptual depth that needs a roadmap; concrete
   questions (an error, a term, a command, syntax) are answered directly.
   Abstraction by default; a syntax stage only on explicit request.
2. **Before** — what and why, an interview of at most 5 thematic axes (one
   follow-up per ambiguous axis, the rest declared as assumptions), the
   paraphrase, a Pareto roadmap with measurable outcomes, and the user's own
   restatement of it.
3. **During** — questions by default, neutral forks, stuck detection by
   behaviour, the escape hatch per request, stage closing by unscaffolded
   explanation or transfer, a retrieval question when resuming.
4. **Register, resources, containment (📦 seeds), memory, moves.**

---

## When This Skill Triggers

- "I want to understand X", "teach me X from the ground up", a field or a
  technology's model to learn as a route.

Not for: one error, one term, one command, "what does this function do",
syntax or how-to questions.
